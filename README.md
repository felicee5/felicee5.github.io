# Felicee5 — Architecture & Graphic Design Portfolio

A responsive student portfolio built with HTML, CSS, and JavaScript.

## About

Hi, I'm Felicee5. I'm an architecture student interested in graphic design,
spatial design, and visual storytelling.

This portfolio showcases my interests, projects, and learning journey.

## Website sections

- About — my background and interests
- Projects — architecture studies and graphic design experiments
- Resume — education and resume PDF
- Contact — a way to get in touch

## Files

- `index.html` — website content
- `style.css` — colours, layout, typography, and responsive styling
- `script.js` — mobile navigation and automatic footer year
- `assets/` — resume PDF and project images

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload the website files to the repository's root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the `main` branch and `/(root)` folder.
6. Click Save.

GitHub will display your website URL in the Pages settings.

## Personalize your website

- Replace `YOUR_EMAIL@example.com` in `index.html` with your email address.
- Add your resume PDF as `assets/resume.pdf`.
- Replace the sample project descriptions with your real projects.
- Add your own project photos, drawings, and graphic design work.
- Add your GitHub profile link when your username is ready.
